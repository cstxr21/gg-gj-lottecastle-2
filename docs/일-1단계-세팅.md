## 참고 (블록 밖 — 사람용)

- **이 단계는 "빈 프로젝트"까지만**이다. 정보 추출·디자인·페이지는 2단계부터.
- **빌드가 느리다고 느껴지면 이 3가지부터 본다.** ① 매 단계 `next build`를 돌리고 있지 않은가 → `npm run typecheck`·`npm run verify`(빌드 없음)로 대체하고 빌드는 단계 마감 때 1회. ② `.next/cache`를 지우고 있지 않은가 → 지우면 매번 풀빌드다. ③ Windows 실시간 검사가 `node_modules`·`.next`를 훑고 있지 않은가 → **Windows 보안 › 바이러스 및 위협 방지 › 설정 관리 › 제외 추가**에 프로젝트 폴더를 등록. 파일 수만 개를 빌드마다 스캔하므로 체감 차이가 가장 큰 항목이다.
- **Tailwind는 반드시 v4** — 5단계 `globals.css`가 v4 문법(`@import "tailwindcss";`·`@theme inline`) 기준이라 v3로 깔면 토큰 설정이 안 맞는다.
- **현장명-영문**만 그 현장에 맞게 바꾸면 다른 일반분양 현장에도 그대로 재사용 가능.
- 분양광고 게재 금지 표현·수치 규정은 콘텐츠 단계(6단계 전역규칙·10~13단계)에서 다룬다. 세팅 단계에선 신경 쓰지 않는다.
