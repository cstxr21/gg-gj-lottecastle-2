# 분양소식 발행 매뉴얼 (7편 체제)

---

## 0. 편수 정책 — 현장당 **7편**

| 슬롯 | 편수 | 시점 | 성격 |
|---|---|---|---|
| **지역 롱테일** | **4** | 15-A (첫 배포 전) | 현장명이 안 들어가는 유일한 칸 = **신규 인지 유입 통로** |
| **현장 사건 뉴스** | **3** | 15-B (사건 발생 시) | 본PF·착공·입주자모집공고. **미리 채우지 않는다** |
| 합계 | **7 (상한)** | | |

- **`{현장명}+X` 롱테일은 쓰지 않는다(폐지).** 현장명을 검색하는 사람은 이미 이 사이트를 안다 — 들어오면 메인·`/sales`·`/floorplan`으로 간다. 분양소식 글을 하나 더 얹어도 전환이 늘지 않고, 오히려 서브페이지 키워드를 잡아먹는다(§3 2관문). 그 fact는 **분양소식이 아니라 해당 서브페이지에 넣는다.**
- **7편도 상한이지 목표가 아니다.** 지역 롱테일은 검색량이 잡히는 만큼만 쓴다 — 2편이 전부 fact 충실한 쪽이, 4편 중 2편이 얇은 쪽보다 낫다.
- **최소 2편.** 빈 `/news` 목록은 미완성 사이트 신호다. 15-A에서 최소 2편은 채우고 배포한다.
- **RSS는 쓰지 않는다.** 7편에서 멈추는 사이트에 피드는 실익이 없다(자주 갱신되는 사이트용). 색인은 `sitemap.xml` + 네이버 서치어드바이저 **"웹페이지 수집요청"**으로 처리한다. 13단계에서 `rss.xml` 라우트를 만들지 않는다.
- **도메인 재사용을 전제로 쓴다.** 현장이 마감되고 같은 도메인에 다음 현장이 올라가면, **현장 사건 글은 전부 폐기물이 되고 지역 롱테일만 승계된다.** 그래서 비중이 4:3이다.
- ⚠️ 편수 상한은 `[G15-COUNT]`가 자동 판정한다(`POSTS` 길이 ≤ 7).

## 1. 필드 규칙 (어기면 빌드가 깨짐)

| 필드 | 형식 | 규칙 |
|---|---|---|
| `slug` | 영문 소문자 + 하이픈 | URL이 됨. **기존 글과 절대 중복 금지.** 예: `{지역영문}-{주제}-{연도}` |
| `category` | 한글 짧은 분류 | 예: `지역분석`, `생활권`, `교통`, `사업진행` |
| `title` | 한 줄 제목 | 25~40자 권장. 과장·미확정 단정 표현 금지 |
| `excerpt` | 1~2문장 요약 | 목록 카드 + `og:description`으로 그대로 노출. **80자 이내(엄수 · `[G14-META]`가 기계 강제)** |
| `date` | `YYYY-MM-DD` | **형식 정확히.** 틀리면 빌드·sitemap이 깨진다 |
| `lead` | 도입 문단 1개 | 그 글의 지역·현장 기본 fact를 자연스럽게 포함 |
| `sections` | 배열 | `{ h2: "소제목", paras: ["문단", ...] }` 를 3~5개 |
| `sourceNote` | 출처·면책 문구 | §6 고정 문구 사용 |

## 2. 콘텐츠 원칙 (필수 — 법규·사이트 정책)

- **미확정 정보 창작 금지**: 분양가·입주일정·세대별 호수·정확한 일정 등은 입주자모집공고 전 단정하지 않는다. "입주자모집공고 시점 기준으로 안내" 식으로 처리.
- **출처는 본문이 아니라 하단 `sourceNote`로**: 검증된 내용은 그냥 사실로 서술하고, 근거 매체(언론사·날짜)는 글 하단 `sourceNote`에 모아 표기한다. 본문 문장에 "보도에 따르면", "~로 알려졌습니다", "(○○일보 등 보도)"를 넣지 않는다 — 신뢰의 근거를 제3자에게 넘기는 문장([6단계](일-6단계-전역규칙.md) §C 출처 자백).
- **사업유형 정확 표기**: "일반분양(분양)"으로 표기. 분양가·계약금은 입주자모집공고 기준으로만 표기하고, 미공고 수치를 단정하지 않는다.
- **GTX-C 등 예정 사업**: "(예정)" 표기하고 "관계기관 계획에 따라 변경될 수 있습니다" 단서를 둔다.
- **청약 종료(선착순 단계)면** 지난 청약 일정을 '안내·혜택'으로 내세우지 않는다(미분양 인식·시점 오인). "청약 마감 · 선착순(잔여세대) 계약"으로 프레이밍한다([12단계](일-12단계-서브-분양-모델하우스.md) §분양 단계 전환).
- 고정 식별자: 상담번호는 사이트 공통값을 따르며 본문에 임의 번호를 쓰지 않는다.

### 어뷰징(블랙햇) 절대 금지 — 검색엔진 페널티·표시광고법 위반

- 키워드 스터핑, 숨김 텍스트, 도어웨이성 얇은 글
- 미확정 정보(분양가·입주 일정) 단정, 미공고 청약 일정·분양가 단정
- 출처 없는 시세 비교("주변 대비 N% 저렴"), 교통·학군 호재 "예정" 없이 단정
- 사실과 다른 내용을 검색 노출 목적으로 창작

## 3. 주제 선정 — 2관문 (하나라도 걸리면 그 주제는 버린다)

### 1관문 — 다른 현장에 복붙 가능한가?

> **현장명·지역명만 바꿔 다른 현장 사이트에 그대로 올릴 수 있으면 금지.**

탈락 예시: `국민평형 84㎡란` · `84 vs 59 평형 비교` · `청약통장 사용법` · `취득세 계산` · `중도금 대출이란` · `분양권 전매란` · `발코니 확장 비용`

이 주제들은 검색 상위를 부동산 대형 블로그·뉴스·카페가 이미 점유해 **현장 사이트 글이 그 자리를 못 잡는다.** 중복 위험만 지고 얻는 게 없다. 전환도 0에 가깝다("취득세 계산" 검색자는 특정 현장 구매자가 아니다).

⚠️ **목록 대조가 아니라 위 한 줄 기준으로 판정한다.** 새 범용 주제는 계속 생긴다.

### 2관문 — 서브페이지가 이미 답하는 질문인가?

> **서브는 "무엇인가"에 답하고, 분양소식은 "어떻게 판단하나"에 답한다.**

| 층위 | 소유 | 예 |
|---|---|---|
| 스펙·수치 | `/floorplan` | 84A 전용면적·구조·타입별 세대수 |
| 조건·절차 | `/sales` | 분양가·계약금·중도금 비율, 일정, 자격 |
| 위치·시설 | `/location` | 역 도보 시간, 통학구, 인접 시설 |
| **지역 맥락** | **분양소식** | 그 지역 고용·개발 데이터로 본 실수요 구조 |

### 지역 롱테일 4편을 고르는 법 (15-A)

현장명이 안 들어가는 칸이라 **아직 이 현장을 모르는 사람**이 들어오는 통로다. 다만 범용 호재 해설로 쓰면 1관문에서 탈락한다.

- ❌ `GTX 개통 시점 정리` · `{대기업} 캠퍼스 정리` — 경쟁 최상, 전환 0, 타 현장 복붙 가능
- ✅ `{산업단지} 고용 {N}명이 {지역} 실수요와 연결되는 구조` · `{대표역} 도보권 신축 {평형} 통학구`

즉 **"호재를 해설하는 글"이 아니라 "그 호재와 이 위치의 거리·시간·수치를 다루는 글"** 이다. 그 지역 데이터에 종속돼야 다음 현장에도 승계된다.

### 현장 사건 뉴스 3편 (15-B)

`{현장명} 본PF` · `{현장명} 착공` · `{현장명} 입주자모집공고` 등 **사건이 실제로 터졌을 때만** 쓴다. 경쟁 0 + 발표 직후 검색 스파이크라 7칸 중 가장 값을 하는 자리다.

- ⚠️ **미리 채우지 말 것** — 슬롯을 채우려 들면 없는 사건을 만들게 된다(§2 미확정 단정 금지).
- 확정 고시·공고된 사실만 서술하고, 근거 매체는 하단 `sourceNote`로.

### 본문·제목 틀 고정 금지

제목이 달라도 **도입부 문형·소제목 구성·결론부가 글마다 같으면** near-duplicate로 묶인다.

- **제목**: `{고정 주력키워드} | {현장명}`처럼 앞부분을 고정하고 현장명만 바꿔 찍어내는 방식 금지. 제목에 그 현장·지역 고유 앵글·고유명사·수치를 최소 1개 넣는다.
- **`h2`**: 고정 3~5개 소제목 세트를 재사용하지 말 것
- **`lead`**: 같은 문형으로 시작하지 말 것 (`{현장명}은 {주소}에 들어서는…` 반복 금지)
- `sourceNote`는 고정 문구가 정상(면책 문구라 예외)

## 4. 글쓰기 규칙

> 기술 SEO(`<title>`·description·canonical·OG·JSON-LD Article·H1/H2·breadcrumb·내부링크)는 `news/[slug]/page.tsx`가 글 데이터로 **자동 생성**한다. 손댈 레버는 **`title`·`excerpt`·`category`·`h2`·문단 텍스트**뿐.

- **키워드는 추측 말고 검색량 기반으로.** 네이버 검색광고 키워드도구·데이터랩·자동완성/연관검색어로 확인한 것만 쓴다([14단계](일-14단계-SEO-GEO.md) §키워드 리서치). 글당 **주력 키워드 1개 + 보조 2~3개**, 글끼리 겹치지 않게(카니발 금지).
- ⚠️ **현장·지역 고유 fact 필수 — 일반론 문장 금지.** 어느 현장·지역에나 그대로 붙는 문장은 쓰지 않는다: "역세권이라 편리", "사통팔달 교통망", "학군 우수", "생활 인프라 풍부", "쾌적한 주거환경", "미래가치 풍부", "합리적인 분양가" 등. **각 문단은 그 지역에서만 나오는 검증된 고유 수치·고유명사를 최소 1개 포함**한다(예: "○○역 도보 7분", "△△IC 차량 5분", "□□초 통학구 배정", "◇◇산업단지 1.2km"). 미검증 수치 창작은 금지이므로 — **확인된 고유 fact가 없으면 그 문단·글을 쓰지 않는다.** 게이트: `[G15-LOCALFACT]`.
- ⚠️ **서브페이지 재진술 금지.** `/location`·`/floorplan`·`/sales`·`/overview` fact를 같은 워딩으로 베끼지 않는다(thin·중복 신호). **분양가·면적 등 상세 수치는 본문에 나열하지 말고 해당 서브페이지로 링크**한다.
- **문단**: 한 문장 = 한 fact 단위(AI 인용 시 잘리지 않게). **질문형 검색에 답하는 자연어(Q&A 친화)**로 → 네이버 AI·AEO 인용에 유리.
- ⚠️ **내부링크·전환 동선(필수)**: 글이 막다른 길이면 유입이 전환으로 안 간다. 7편뿐이라 **한 편의 전환 기여가 크다.** 정본 = [11단계](일-11단계-서브-단지정보.md) §내부링크 시스템 — **본문 맥락 링크 0~2개**(그 문장에서 자연스러운 곳에만·같은 URL 1회·서술형 앵커) + **하단 전환 CTA는 관심고객 등록 버튼 1개**(`PageOutro` → `/modelhouse#reservation`). 카드 블록·링크 매트릭스·중복 CTA 금지. 글끼리도 관련 있는 편끼리 1회씩 연결해 주제 묶음을 만든다.
- **발행 후 성과 확인(운영 1~2개월 뒤 · 월 1회)**: 네이버 서치어드바이저 **유입 검색어** × GA4 **전환**(`form_submit_success`·`tel_click`)을 대조한다. 7편 체제라 편수 조절용이 아니라 **① 15-B 사건 글을 쓸 가치가 있는지 ② 기존 글 중 보강할 게 있는지**를 판단하는 용도다. 데이터가 아직 없으면 키워드도구 검색량으로 판단한다(§5).
- **AI 유입**: 자연어 fact + 발행일(`date`)이 그대로 AI 인용 신호가 된다. 별도 작업 없음.
- **제목 CTR 4요소 (최소 1개)**: 숫자("도보 7분", "3단계") · 질문형("진짜일까?") · 구체 지역·역명·고유명사 · 손해회피("이거 모르면 손해")

## 5. 작성 전 프리플라이트 (쓰기 전 4단계 — 수동·AI 공통)

1. **편수 확인** — `src/lib/news.ts`의 `POSTS` 길이가 **7 미만**인가. 7이면 새 글을 쓰지 않는다(기존 글 보강).
2. **2관문 판정(§3)** — ① 타 현장 복붙 불가 ② 서브페이지가 답하는 질문 아님
3. **기존 글 확인** — `news.ts` 전체 + 공용 [분양소식-소재대장](../분양소식-소재대장.md) 대조. 주력 키워드가 겹치면 버린다.
4. **검색량 확인** — 네이버 키워드도구·자동완성·연관검색어로 실제 검색량·표기 변형까지 확인. **근거 없는 추측 키워드로는 한 편도 쓰지 않는다.**

## 7. 작성 후 체크리스트

- [ ] **프리플라이트(§5) 완료**: 편수 < 7 → 2관문 판정 → 기존 글·소재대장 대조 → 검색량 확인
- [ ] **편수 상한(§0)**: `POSTS` 길이 **7 이하** · 지역 롱테일 4 / 사건 3 배분을 넘지 않는가 · **`{현장명}+X` 롱테일이 아닌가**(폐지된 슬롯)
- [ ] **2관문 통과(§3)**: ① 타 현장 복붙 불가 ② 서브페이지가 답하는 질문 아님
- [ ] **공용 [분양소식-소재대장](../분양소식-소재대장.md) 대조 + 발행 후 1줄 추가** — 빠뜨리면 다음 현장이 같은 글을 쓴다
- [ ] **현장·지역 고유 fact(§4)**: 일반론 문장 0 · 각 문단에 검증된 고유 수치·고유명사 최소 1개 (`[G15-LOCALFACT]`)
- [ ] **틀 고정 0(§3)**: 제목이 현장명만 스왑한 형태가 아닌가 · `h2` 구성·`lead` 문형이 기존 글과 다른가
- [ ] **서브페이지 재진술 0(§4)**: 고유 앵글로 작성, 상세 수치는 서브로 링크
- [ ] **내부링크·전환 동선(§4)**: 본문 맥락 링크 0~2개(같은 URL 1회) + 하단 관심고객 등록 CTA 1개 — 막다른 글 0
- [ ] `slug` 중복 0 · `date`가 `YYYY-MM-DD` 형식 · `excerpt` 80자 이내
- [ ] 객체를 `POSTS` 배열 **맨 앞**에 넣었는가 (최신 글이 위로) · 쉼표 빠짐 없이 닫혔는가
- [ ] 미확정 정보 단정 / 출처 자백 문장이 없는가(§2)
- [ ] 확인은 `npm run typecheck` + `npm run verify -- --stage=15` (둘 다 빌드 없음 · 수 초)
      ⚠️ **글 한 편마다 `npm run build`를 돌리지 말 것.** 로컬 풀빌드가 필요한 건 배포 직전 `npm run verify:build` 1회뿐이다.
- [ ] 재배포 후 `/news`·`/sitemap.xml`에 반영 확인
- [ ] **네이버 Search Advisor "웹페이지 수집요청"** 제출(즉시 색인 — RSS를 안 쓰므로 이게 색인 통로다)
