## 메타 (IA 정본 값)

- **TITLE** `{현장명} | 분양 홈페이지` (브랜드 + "분양 홈페이지" 꼬리 — 현장명 직접검색 유입 시 공식 사이트임을 SERP에서 즉시 식별시키는 용도. `/modelhouse`가 "방문예약·분양상담", `/sales`가 "분양가·청약·일정" 정본 소유하므로 메인 꼬리는 그 키워드들과 겹치지 않게 "분양 홈페이지"로 고정. 네이버 30자 이내, READ-ONLY)
- **OG:TITLE** `{현장명} — {위치} {사업유형} {N}세대`
- **META DESC**(≤80자) `{현장명} 분양안내·방문예약. {위치} {N}세대 사업개요·입지·분양가 확인, 상담 {전화}.`
- **H1** `{현장명}`
- **H2**: 인트로 `{브랜드 컨셉 한 줄}` + 섹션 주제어(사업개요 · 입지환경 및 미래가치 · 프리미엄 · 단지안내 · 평면도 · 분양안내 · 모델하우스 · 분양소식 · 자주 묻는 질문 · 관심고객등록) + ABOUT `한눈에 보는 단지 정보`. (※ 섹션 H2 = NAV 주제어 라벨 그대로 / ABOUT H2도 **현장명 접두어 생략** — 브랜드는 H1·본문이 받침, 아래 ⚠️ 일관.)
  - ⚠️ **메인 섹션 H2는 주제어만**(브랜드 접두어 제거) — 브랜드는 H1·title·JSON-LD·ABOUT·본문이 받침. 서브가 "{현장명}+주제" 롱테일을 소유하므로 메인 H2 브랜드 반복은 카니발.

## 콘텐츠 원칙

- **분량**: 본문 fact 800~2,000자(정보 밀도 우선). ⚠️ **분량은 결과 — [3단계 ⑦ 전사 대장](일-3단계-검증보강.md)의 메인 귀속 핵심 스펙**(총세대·동수·층수·전용면적 구성·입주예정·사업주체)을 ABOUT 본문 텍스트로 전사하면 자연 충족. 하한만 맞춘 채우기·이미지-only 금지(메인은 요약 허브라 상세 수치는 teaser 1줄+서브 링크로 분산하되, ABOUT엔 단지 핵심 스펙을 텍스트로).
- **메인 = 요약 허브**: 각 섹션(사업개요·입지·프리미엄·단지·평면도·분양·모델하우스·소식·FAQ)을 **1블록 요약 teaser + 서브 링크**로만. 상세·동일 워딩은 서브에. 한 섹션에 다른 영역 콘텐츠를 펼치지 말 것.
- **이미지**: Hero·MagBlock 이미지는 **실제 비율 무크롭**(잘림 0)으로 가용 비주얼 최대 활용.
- ★**near-duplicate 금지(전 구간 공통)**: 섹션 간·메인↔서브에 같은 문장 복붙 금지. 같은 fact라도 워딩을 바꾼다. (이 문서에서 가장 자주 어기는 규칙)
- ★**현장명 본문 밀도 — 대명사 환원**(정본 = [14단계 §브랜드 토큰 본문 밀도](일-14단계-SEO-GEO.md)): 본문에서 "본 단지·본 현장·이 단지"로 받은 자리를 **현장명으로 환원**한다. 현장명이 title·H1·alt·JSON-LD 같은 **기계 판독 자리에만 몰리고 본문 텍스트엔 거의 없는 상태 = 네이버 본문 매칭 손해**(경쟁사 실측에서 확인된 실패 패턴 · 메인이 가장 심하게 나타나는 지점). 진단선 **250자당 1회**(400자당 1회보다 묽으면 보강 · 100자당 1회보다 촘촘하면 스터핑 점검) — ⚠️ **페이지별 "현장명 N회" 목표표를 만들어 채우지 말 것**(밀도는 결과지 KPI가 아니다). 보강 순서 ① 대명사 환원 → ② 문단 첫 주어 복원 → ③ 그래도 묽으면 요약 블록 추가(**서브 링크 필수·서브 본문 복제 금지**, 위 §메인=요약 허브 준수). **H2 브랜드 접두어 금지 원칙은 그대로**(위 ⚠️) — 늘리는 건 본문이지 헤딩이 아니다.
- ⚠️ **청약 종료 후엔 '지난 청약 일정' 나열 금지(미분양 인식 유발)**: 정규 청약(공고·특공·1·2순위·당첨·정당계약)이 끝났으면 지난 날짜를 열거하지 말고 **"청약 접수 마감 · 선착순 동·호 지정 계약 진행 중"**으로 간결·긍정 표기 — **분양 teaser·FAQ·ABOUT 공통**. 입주자모집공고일은 **분양가 기준일**로만 유지(일정 나열용 아님). 선착순 진행은 1차 출처 검증 시에만 단정 — **현장별 확인 출처(언론 보도·시행사 공지 등 매체명+날짜)는 현장 산출물 `검증리포트.md`에 기록**(이 범용 md에 박지 말 것). 상세 정본·`/sales` 분기 = [12단계 §분양 단계 전환](일-12단계-서브-분양-모델하우스.md).

## 구성 순서 (UI §2.1 정본)

**Hero → 인트로(브랜드 컨셉) → 섹션 매거진 블록(01~0N) → 분양소식 → FAQ → 관심고객등록(폼) → ABOUT(정보성) → 다크 푸터.**
- 관심고객등록 폼 = **하단부 최종 전환 CTA**(순서상 ABOUT 직전 · 실제 **푸터 바로 위 마지막은 ABOUT** 정보블록).
- 분양소식·FAQ는 **2단 카드 또는 풀폭 분리** 둘 다 허용(분양소식이 featured+요약으로 두꺼우면 분리가 균형에 유리).
- 배경 `bg-surface`(흰)↔`bg-background`(아이보리) 교차, **같은 색 인접 금지**, 마지막 **다크 푸터(`bg-ink`)**.

### Hero (`HomeHero`)

**[공통]**
- **높이**: 데스크탑 `lg:h-screen` · 모바일 `min-h-[calc(100svh_-_56px)]`(콜바 56px 제외, `svh`로 주소창 출렁임 방지). ⚠️ **arbitrary 값 언더스코어 필수**(`100svh_-_56px`) — 빠지면 CSS 무효 → 높이 0으로 콘텐츠가 상단에 몰림(실발생 버그).
- **헤드는 차분한 배경(하늘·여백) 위**. 타워·디테일 위에 큰 글자 금지(가독·우아함 손해).
- **상단 공백 방치 금지** — 카피·핵심지표로 균형.
- 헤더: 최상단 투명+흰 글자 → 스크롤 24px↑ `bg-ivory/95` 솔리드. **밝은 하늘 위 흰 nav용 상단 스크림** 확보.
- 카피: eyebrow(영문 장식, 너무 얇게 금지) → 한글 헤드(serif 대형) → 메타(입지·세대수 fact 한 줄) → CTA. 상단 좌측 에디토리얼 또는 가운데.
- 핵심지표(세대수·전용·입주·역) 노출하되 **무거운 하단 불투명 바 금지** → 헤어라인 행.
- 히어로 CTA = **관심고객 등록(`/modelhouse#reservation`) + 전화 버튼(`tel:`{전화} — 아이콘+번호만, 텍스트 라벨 없음) 2개 나란히**, **모바일·태블릿 숨김**(콜바 중복, `hidden min-[1360px]:flex`).
- 50대 가독성·`prefers-reduced-motion` 정지컷 폴백.

**매체 선택 (이미지 / 영상)** — 제약이 달라 나눈다(안 나누면 "빈 상단·영상 모션 가림" 실수 반복).
- **[A] 이미지(정적)**: `next/image` priority+webp. 텍스트 배치 자유(풀 오버레이·듀오톤). 생동감은 은은한 Ken Burns까지.
- **[B] 영상**: 자산 `public/videos/hero/hero-main.mp4` + poster=영상 첫 프레임 webp, 자동재생 `muted playsinline loop`. **압축·폴백은 [6단계](일-6단계-전역규칙.md) §B 영상 규칙**(1280폭·`-an`·`+faststart`·≤1MB·저전력/저모션 시 poster). ⚠️ **모션 존(보통 하단 1/3)을 바·스크림으로 덮지 말 것**(영상이 정지처럼 보임) — 스크림은 텍스트 쪽만. **심리스 루프(시작=끝)**.

✅ **권장 기본값 = [A] 이미지 히어로**: 원본 단지 조감 CG 한 장(선명, 4단계 hero category keep 컷) + 느린 Ken Burns(scale 1.04→1.09 / 30초±) + (선택) 텍스트 clip-path 와이프 + 라이트 스윕 1회. **현장별 최종 채택(A/B 선택·실제 파일명)은 현장 산출물(`이미지-배치표.md` 등)에 기록** — 이 범용 md에 특정 현장 파일명을 박지 말 것.

### 섹션 매거진 블록 (`MagBlock` 01~0N)

- 각 섹션 = **이미지 + 숫자 인덱스(`01 — Overview`, 브론즈 이태릭) + 한글 H2(serif 26~34px) + fact 문단 + 자연어 링크**를 **한 블록**으로. 좌우 교차(`reverse`) 2단. **이미지엔 링크·hover 줌 없음**(이동은 `linkLabel`로만).
- **fact 문단 = 2~3문장 티저**(슬로건 한 줄 금지). 검증 fact만, 미확정·운영계획은 단정 금지("안내"/"예정").
- ★**"풍성하되 어뷰징 0"(실수 잦은 지점)**:
  - **풍성함 = 정보 밀도**: 각 섹션에 그 영역 검증 fact 1~2개 이상 구체 포함(개요=세대수·층수·일반분양, 타입=주택형별 세대수·면적, 분양=공급 조건·선착순 단계·입주[**분양가 금액은 메인 미기입 → `/sales` 정본**, 아래 ⚠️ 참조], 모델하우스=주소·관람시간). 슬로건/형용사로 길이만 늘리지 말 것.
  - **어뷰징 0** (규칙 원천 = [6단계 ★전역 가드 ⟨어뷰징⟩] 준수): 메인 티저는 특히 과장 수식어("최고급"·"초역세권")·도배·near-duplicate·채우기 문장 0.
  - 점검: 각 티저가 **검증 fact 포함 + 서로 다른 워딩 + 과장·반복 0** 이면 통과.
- ⚠️ **분양가 상세 숫자는 `/sales` 정본에만 — 메인엔 분양가 금액 미기입**: 분양 티저·ABOUT·FAQ 미리보기 어디에도 분양가 범위/금액(억·만 원·원)을 적지 말 것. 메인 분양 티저는 "분양가·공급 조건을 입주자모집공고 기준으로 안내" + **linkLabel `분양가·일정 안내` → `/sales`** 링크만. (분양안내에 상세 입력 시 near-duplicate·키워드 카니발 방지.) ABOUT은 "자세한 금액은 분양안내에서 확인"으로 링크 유도.
- **이미지 잘림 방지**: 고정 `aspect-[4/3]`+`object-cover`로 묶으면 다 잘림 → 컨테이너 비율=이미지 실제 비율(`style={{aspectRatio:w/h}}`) 또는 튀는 세로 컷은 가로 이미지로 교체.
- ⚠️ **이미지 미확보 또는 "사용자 직접 첨부 예정"으로 지정된 섹션 → 임의 이미지 삽입 금지(절대 실수 금지)**: 해당 섹션은 MagBlock `placeholder` prop으로 **빈 중립 플레이스홀더 박스**("이미지 준비 중 · 사용자 첨부 예정", `border-dashed` — 사양은 [8단계 §6](일-8단계-공통컴포넌트.md))를 렌더한다. **자동 큐레이션·임의 이미지 삽입·재생성 금지**(다른 섹션 이미지 작업 시에도 지정 섹션은 손대지 말 것). ★**메인의 평면도·분양안내·모델하우스 3섹션 = 사용자 직접 첨부 고정 슬롯(실사진 또는 디자인 정보카드)**(일반분양·민간임대·지주택 3사업유형 공통 정책). 4단계에서 `floorplan`/`sales`/`modelhouse` 카테고리 이미지를 keep했더라도 그건 **서브페이지 전용** — 메인 티저엔 넣지 않는다. 그 외 섹션의 첨부 지정이 추가로 필요하면 현장 산출물(`이미지-배치표.md`)에 기록한다.
  - **3슬롯의 정상 상태는 셋 중 하나뿐**: ① **placeholder 유지**(자료 수령 전 = 기본) ② **사용자 실사진 연결 완료** ③ **디자인 정보카드 연결 완료**(실사진이 없을 때의 정본 경로 — 아래 ★③). 그 사이에 임의 이미지가 들어가는 상태는 없다. ③도 사용자가 만든 파일을 `--user --slot=`으로 넣는 것이라 **②와 완전히 같은 경로·같은 게이트**를 탄다(게이트 로직 변경 없음). `[G10-IMG]` 게이트는 **①②③을 모두 PASS로 인정**(슬롯별로 ①·②·③ 중 하나면 GREEN)하고, 4단계 카테고리 이미지가 메인에 노출되면 RED. 슬롯을 **부분만 채워도**(1~2개) 나머지는 placeholder로 남아 GREEN이다.
  - ★**③ 디자인 정보카드 — 실사진이 없을 때의 정본 처리**(현장 대부분이 여기 해당): 모델하우스 실내컷·실제 평면도가 없으면 **스톡·AI 실사진 흉내로 채우지 말고 정보카드로 만든다.** 슬롯별로 담을 내용은 아래 고정 — **전부 검증된 실값만**([6단계 ★전역 가드 ⟨어뷰징⟩](일-6단계-전역규칙.md) 동일 적용).

    | 슬롯 | 카드 성격 | 담을 실값 |
    |---|---|---|
    | `floorplan` | **타입 구성** | 타입명(84A·84B…) · 전용면적 · 타입별 세대수 |
    | `sales` | **공급 개요**(분양안내) | 총 세대수 · 타입 라인업 · 일정 스텝 (⚠️ **분양가 금액은 넣지 말 것** — 위 ⚠️ 분양가 상세는 `/sales` 정본에만) |
    | `modelhouse` | **방문 안내** | 견본주택 주소 · 관람시간 · 예약방법 · 약도 |

    - ⚠️ **`floorplan` 슬롯을 정보카드로 채울 때는 섹션 제목도 "평면도" → "타입 안내"로 함께 바꾼다.** 실제 도면이 아닌 것을 "평면도"로 제시하면 오인 표시다. 실제 도면을 확보하면 그때 ②로 교체하고 제목을 되돌린다.
    - ⚠️ **`modelhouse` 슬롯의 목적은 로비 자랑이 아니라 방문 예약 유도**다. 실내 이미지가 없다고 감점이 아니라, "어디로·언제·어떻게 가는지"가 전환에 직접 붙는다 — 실사진이 생겨도 방문 정보는 섹션 텍스트에 남긴다.
    - **금지(표시광고법·라이선스 — 발견 즉시 교체)**: ⓐ **도면 흉내**(실제 도면 아닌 그래픽을 평면도처럼 제시) ⓑ **AI 생성 인테리어·로비를 실사진처럼 배치**(실재하지 않는 견본주택 오인 — 가장 위험) ⓒ 스톡 사진 ⓓ 지도 서비스 화면 캡처(약도는 직접 제작) ⓔ **이미지 안에 전화번호·URL 굽기** — 번호는 반드시 HTML 텍스트 + `tel:` 링크로(이미지에 구우면 현장별 번호 교체 불가 · 번호 변경 시 전량 재제작 · 검색엔진 판독 불가 · 확대 시 깨짐).
    - **가짜보다 빈칸이 낫다** — 실사진도 확정 실값도 없는 슬롯은 ①placeholder로 두는 것이 정답이다. 채우려고 ⓐ~ⓒ로 가지 말 것.
    - **제작 규격은 [5단계 §물질화](일-5단계-디자인시스템.md) 정본**(아트보드 가로 1600×1200 고정 · 브랜드 토큰 사용 의무 · 3장 동시 제작). 만든 뒤 연결 절차는 ②와 완전히 동일하게 아래 ★ 절차를 그대로 탄다.
  - ★**사용자가 파일을 준 뒤 연결 절차(이 순서 그대로 · 임의 변환·임의 배치 금지)**:
    1. 원본 파일을 프로젝트 안 아무 경로(권장 `docs/user-images/`)에 둔다. **파일명·확장자·용량·비율 무관**(휴대폰 사진·캡처본 그대로 OK, 원본은 변경하지 않는다).
    2. `npm run images -- --user=<원본경로> --slot=floorplan|sales|modelhouse` 실행 → `public/images/home/{slug}-home-{slot}-NN.webp`로 **webp 변환·리사이즈·용량 상한·`{slug}-` 접두 파일명이 자동 적용**된다([5단계 §물질화 스크립트](일-5단계-디자인시스템.md) `--user` 모드). 출력에 찍히는 **`ratio=w/h`와 파일 경로를 그대로** 다음 단계에 쓴다. **손으로 변환·리네임 금지** — `[G14-IMGNAME]`·`[G16-IMGWEIGHT]`·`[G16-CLS]` 규격을 동시에 맞춰야 한다.
    3. 해당 MagBlock에서 `placeholder` prop을 제거하고 `image`(2의 경로)·`ratio`(2의 출력값)·`alt`를 연결한다(현장이 `src/lib/images.ts` 매니페스트를 쓰면 HOME 항목에 등록 후 참조, 아니면 `content.ts` 섹션 블록에 직접). 비율은 **원본 실비율 그대로**(무크롭 — 위 §이미지 잘림 방지).
    4. `alt`는 키워드 충실 자연어(예 `{현장명} 84A 평면도` · `{현장명} 모델하우스 내부`) — 파일명·키워드 나열 금지. ⚠️ **③ 정보카드일 때는 카드 내용 그대로 쓴다**(예 `{현장명} 주택형별 전용면적·세대수 안내` · `{현장명} 견본주택 방문 안내 — 주소·관람시간`) — 실사진을 가리키는 alt("평면도"·"모델하우스 내부")를 정보카드에 붙이면 **오인 표시 + 이미지 SEO 불일치**다([14단계](일-14단계-SEO-GEO.md) 이미지 SEO).
    5. `npm run verify -- --stage=10`으로 `[G10-IMG]` GREEN 확인.
  - ⚠️ **여기서 자주 나는 사고 3가지**: ① 사용자 파일을 `public/images/<category>/`(4단계 카테고리 = 서브 전용 디렉토리)에 넣음 → 메인 노출이 **카테고리 누출로 잡혀 RED**. **사용자 첨부는 `public/images/home/`에만.** ② 변환 없이 원본 jpg/png를 그대로 연결 → 용량(`[G16-IMGWEIGHT]` ≤800KB)·파일명(`[G14-IMGNAME]` `{slug}-` 접두) RED. ③ 파일만 넣고 섹션 연결을 빠뜨림 → 배포 직전 `[G16-UNUSED]`(미사용 자산 0)에서 RED — 연결하지 않을 파일은 `public/`에 두지 말 것(원본은 `docs/user-images/`에 보관).

### ★ 위치/지도 안내 — `MapLinks` 길찾기 버튼 미사용
- 현장(단지) 위치는 **입지환경 MagBlock 이미지(현장 지도 CG) + `/location`**, 견본주택 위치는 **모델하우스 위치안내 + 주소 텍스트**로 안내.
- ⚠️ **외부 지도앱 길찾기 버튼(`MapLinks`)은 전 페이지 미사용** — 이탈로 전환(방문예약)에서 벗어나고 SEO·AI 유입 기여가 0. 주소·전화는 텍스트 + `LocalBusiness` JSON-LD([12단계](일-12단계-서브-분양-모델하우스.md))로 구조화 노출.

### 분양소식 / FAQ (`lib/news.ts` · `lib/faq.ts` 단일 소스)
- **분양소식**(`news.ts`): 홈은 **발행글(POSTS) 우선 + 언론 보도(PRESS) 병행** 2단 — 좌측 발행글 최신 3편(카테고리·날짜·제목·요약, **`/news/[slug]` 내부링크**), 우측 언론 최신 **4건**(매체·날짜·제목, **외부 원문** `target=_blank rel=noopener`). ★**건수 규칙 = `min(4, 전체의 절반)`** — 보도가 6건 미만이면 4건을 다 싣지 말고 절반만 (예: 보도 4건 → 홈 2건). 메인은 요약 허브라 **`/news`에 갈 이유를 남겨야 한다** — 전량을 홈에 실으면 서브가 빈손이 되고 홈만 길어진다. ⚠️ **보도 0건이면 그 자리는 렌더하지 않는다**(빈 섹션·빈 ※ 금지 — [8단계](일-8단계-공통컴포넌트.md)).. 발행글 0편이면 보도 단독. 우상단 더보기 → `/news`. (전체는 13단계)
- **FAQ**(`faq.ts`): 홈은 **대표 질문+간단답 미리보기** + 전체 → `/faq`.
  - ★**미리보기 5개 권장(3개로 줄이지 말 것)**: 정보성 Q&A가 많을수록 롱테일 표면↑·체류↑·이탈↓. 단 **분양가 등 숫자 상세가 `/sales` 정본인 항목의 질문은 홈 미리보기에서 제외**(메인 분양가 숫자 미노출 정책과 일치 — 예: `FAQS.filter(f=>!f.q.includes("분양가")).slice(0,5)`). 전체 답변은 `/faq`에서 노출.
  - ★**답변 = 티저와 다른 워딩**(Q&A 톤 + 티저에 없는 추가 정보: 세대수=조합원 제외 맥락, 주택형=A·B 평면차+타입 링크, 입주=개별 통보, 청약=잔여세대 상담). 티저 복붙 금지.
  - ⚠️ **FAQPage JSON-LD는 `/faq`에만**(홈 미노출 — 스키마 중복 방지, [6단계](일-6단계-전역규칙.md) §F).
- 답변·요약은 3단계 검증 fact만(불확실 = "입주자모집공고 기준 추후 안내", 창작 금지). ⚠️ **출처는 크레딧 자리에만** — 보도 근거는 PRESS 카드(매체·날짜·원문)·하단 ※ 주석으로 정확히 표기하고, **답변·요약 문장 안에는 "보도에 따르면·알려졌다"류를 넣지 않는다**([6단계](일-6단계-전역규칙.md) §C 출처 자백).
